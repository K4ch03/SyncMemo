狭い画面でもツールバーを1行で表示し、横スクロールできます。元に戻す・やり直すを先頭へ移動しました。文字サイズと表示倍率はラベルなしのプルダウンです。上下余白を縮小し、斜体機能（ボタン・ショートカット）を無効化しています。既存メモの斜体も編集時に解除されます。文字色・背景色のパレットはスクロール領域の外に表示して見切れを防ぎます。
